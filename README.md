A tiny program for the [Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — a kind, funny fortune for
a houseplant, in 120 characters or fewer:

> This week, a sunbeam will find you at last — lean in, drink it slowly, and forgive the human for the extra water.

A prediction with real fortune cadence, warm about the plant and its
keeper, written for this plant on this windowsill.

## Run it

```sh
python3 main.py
```
